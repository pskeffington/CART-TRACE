# CART-TRACE Capstone Submission Checklist

## Purpose

Final submission inventory for the capstone package. This checklist separates public synthetic deliverables from any approval-dependent institutional additions.

## Core scholarly files

- [ ] `THESIS.md` aligned to final scope.
- [ ] `ROADMAP.md` aligned to final milestone state.
- [ ] `docs/scholarly/capstone_manuscript_scaffold.md` tightened to final wording.
- [ ] `docs/scholarly/capstone_presentation_narrative.md` reviewed against the final figure/table order.
- [ ] governance/reproducibility statement included in the final manuscript.
- [ ] limitations section reflects actual access/validation status.

## Figures and tables

- [ ] Main Figures 1–3 included and labeled synthetic where applicable.
- [ ] Main Tables 1–5 included.
- [ ] Supplementary Figure S1 included.
- [ ] Supplementary Tables S1–S4 included.
- [ ] Every numeric value in generated outputs is traceable to a controlled source.
- [ ] Captions do not imply empirical institutional findings when only synthetic data are shown.

## Presentation

- [ ] Capstone question appears early and exactly matches the final scope.
- [ ] The data-structuring architecture is shown before results.
- [ ] Synthetic validation strategy is explained before synthetic results.
- [ ] Gate 6 is presented as methodological readiness, not authorization.
- [ ] Governed empirical results slide is populated only if approved results exist; otherwise it states that execution is pending or unavailable.
- [ ] Limitations and contribution are distinct slides.
- [ ] Final conclusion matches the manuscript conclusion.

## Reproducibility

- [ ] Final reproducibility audit checklist completed.
- [ ] Current-head CI is green.
- [ ] Generation/rendering commands succeed.
- [ ] Automated test suite passes.
- [ ] Final commit SHA and Actions run ID recorded.
- [ ] Repository release/tag decision recorded.

## Scope and claims

- [ ] Project is described as retrospective and descriptive.
- [ ] No claim of eligibility determination, treatment readiness, product selection, prospective decision support, toxicity prediction, or causal treatment effect is made.
- [ ] Level-of-care trajectory is not described as a direct toxicity or physiologic-severity measure.
- [ ] Synthetic validation is not presented as external clinical validity.
- [ ] Any institutional findings are clearly separated from synthetic results.

## Governed-data branch

If institutional execution occurred:

- [ ] authorization and approved environment documented outside the public repository;
- [ ] local mapping version recorded;
- [ ] data-quality and reconstructability summaries completed;
- [ ] validation/adjudication completed as prespecified;
- [ ] only approved aggregate findings inserted into public scholarly artifacts.

If institutional execution did not occur:

- [ ] manuscript explicitly states that empirical institutional validation was not performed;
- [ ] governed sections remain planned-validation descriptions rather than simulated results;
- [ ] final conclusion remains limited to computational validity and methodological readiness.

## Final package

- [ ] manuscript/report
- [ ] presentation
- [ ] public repository
- [ ] figure/table bundle
- [ ] supplementary materials
- [ ] reproducibility statement
- [ ] governance statement
- [ ] final audit record

## Completion criterion

The submission package is complete when all public claims are supported by the controlled repository evidence, all final artifacts agree on scope and status, the synthetic results reproduce cleanly, and any governed-data additions have been reviewed for release.
