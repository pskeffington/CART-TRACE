# CART-TRACE Scholarly Integration — Results Template

## Status

Template only. This document must not be populated with simulated values presented as observed clinical results.

## Synthetic results

Report only the controlled synthetic findings already generated from the frozen truth set, with explicit labeling as synthetic validation evidence.

## Governed cohort results

If authorized and completed, report:

- cohort accounting and valid infusion anchors;
- source-domain availability;
- mapping coverage/version;
- reconstructability classes;
- follow-up sufficiency;
- representation-validation concordance;
- discrepancy categories/resolutions;
- frozen utilization metrics and trajectory summaries.

## Required separation

Maintain distinct subsections for:

1. synthetic computational validation;
2. governed representation validation;
3. descriptive empirical utilization findings.

Do not combine these into a single validity claim.

## Descriptive outputs

Where governed data are available, report only descriptive outputs supported by the frozen contract, including care-state durations, transitions, discharge timing, acute-care returns, unknown/uncertain burden, and metric availability.

## Prohibited inference

Do not infer toxicity severity, treatment quality, appropriateness of transfer/discharge, comparative treatment effectiveness, or causal relationships from level-of-care trajectories alone.

## If governed access is unavailable

State explicitly that no empirical clinical-results section was produced. Present the synthetic validation and governed validation design as the completed capstone evidence, without fabricating placeholders as observations.
