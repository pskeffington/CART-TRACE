# CART-TRACE Governance and Reproducibility Statement Template

## Status

Template only. This statement is intended for the final capstone manuscript or appendix.

## Reproducibility

The public repository contains the frozen canonical model, machine-readable schemas and synthetic mapping, six-case synthetic truth set, deterministic reconstruction and metric logic, automated tests, generated synthetic outputs, and controlled scholarly artifacts. Frozen analytic semantics require explicit gate-impact review before change.

## Validation layers

CART-TRACE distinguishes:

1. computational validity established with synthetic truth cases and automated tests;
2. methodological readiness established through the governed-data protocol and operational-review package;
3. representation validity, which requires approved local source-concordance review;
4. descriptive empirical findings, which require authorized governed data.

These layers are not interchangeable.

## Governance

Institutional data use is conditional on applicable approval, privacy, security, and data-use requirements. PHI, local identifiers, credentials, restricted mappings, raw source records, and patient-level adjudication evidence remain in the approved governed environment.

## Public outputs

Only approved, non-identifying aggregate results may leave the governed environment. Public artifacts must preserve denominator definitions, unavailable/uncertain statuses, mapping/version provenance, and the distinction between synthetic and observed data.

## Software and method integrity

Institution-specific preprocessing may map local source semantics to the frozen canonical representation, but it may not silently add states, alter interval semantics, change precedence/conflict behavior, redefine metrics, modify follow-up interpretation, or change synthetic-oracle expectations. Such changes require explicit gate-impact review and renewed validation.
