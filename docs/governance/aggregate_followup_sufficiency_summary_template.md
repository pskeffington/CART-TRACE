# CART-TRACE Aggregate Follow-Up Sufficiency Summary Template

## Status

Template only. No governed patient data are represented in this public artifact.

## Purpose

Summarize metric-specific observation sufficiency after approved governed execution while preserving the frozen distinction between observed positive events, defensible observed-zero results, incomplete follow-up, and unavailable status.

## Rules

1. A documented qualifying positive event remains observed even if later follow-up is incomplete.
2. A negative result requires complete ascertainment through the requested horizon.
3. Incomplete follow-up, not calculable, and unavailable statuses are never encoded as zero.
4. Denominators must be reported explicitly for every summary.
5. Public reporting requires approved aggregate disclosure review.
