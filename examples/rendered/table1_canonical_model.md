# Table 1. CART-TRACE canonical data model and deterministic transformation rules

This specification-oriented table summarizes frozen research objects and transformation semantics. It is descriptive of the method and does not contain governed clinical results.

| Object / rule | Definition | Required fields or states | Temporal semantics | Uncertainty / provenance behavior | Implementation artifact |
|---|---|---|---|---|---|
| Therapy episode | Treatment-centered unit of analysis anchored to one CAR T-cell infusion | `episode_id`, infusion timestamp, configured study window, provenance context | Infusion defines relative time 0; primary analytic window `[0,720)` | Missing/insufficient anchor can make an episode non-reconstructable | `schemas/therapy_episode.schema.json`; `docs/episode_model.md` |
| Encounter input | Source-like hospital encounter or location record used for reconstruction | source identifier, start/end timestamp, source care/location label, encounter category where available | Absolute timestamps retained; end may be explicit null/open | Source values remain distinct from canonical values; source identifier retained | `schemas/encounter_input.schema.json`; `docs/clinical_data_structuring_framework.md` |
| Care-state interval | Canonical treatment-relative representation of observed care state over time | episode/interval identifiers, canonical state, start/end timestamps and relative hours, provenance | Half-open `[start,end)` interval semantics; adjacent intervals may share boundaries | `unknown` and uncertainty metadata are explicit; source record IDs retained | `schemas/care_state_interval.schema.json`; `cart_trace/reconstruction.py` |
| Transition | Typed change between canonical states | from/to states, transition type, timestamp/relative hour, provenance | Occurs at a canonical interval boundary | Ambiguous or unsupported changes remain explicit rather than inferred beyond rules | `schemas/transition.schema.json`; `cart_trace/reconstruction.py` |
| Provenance record | Audit linkage from derived object to source evidence and transformation context | source record IDs, mapping/transformation version, derivation context | Follows the timestamps of the linked canonical object | Required to preserve source-to-analysis traceability | `schemas/provenance.schema.json` |
| Metric result | Versioned post-infusion utilization output derived from validated intervals/transitions | episode, metric version, analytic window, values, status, contributing IDs | Primary window `[0,720)` unless metric states otherwise | Status distinguishes observed, observed zero, not applicable, not calculable, and incomplete follow-up | `schemas/metric_result.schema.json`; `cart_trace/metrics.py` |
| Infusion-relative time | Continuous elapsed time from infusion | event timestamp and infusion timestamp | `(event_timestamp - infusion_timestamp).total_seconds()/3600`; no flooring | Timestamp precision is not manufactured | `cart_trace/reconstruction.py`; `docs/clinical_data_structuring_framework.md` |
| `[start,end)` rule | Canonical interval boundary convention | start inclusive; end exclusive | Shared adjacent boundaries do not overlap; events at exactly +720 h are outside the primary window | Prevents double counting at interval and study-window boundaries | `docs/clinical_data_structuring_framework.md`; tests |
| Overlap precedence | Deterministic resolution of overlapping source evidence | versioned mapping and priority/precedence values | Stable ordering and documented tie-breaking | Resolution is rule-based and reproducible; source evidence remains auditable | `config/synthetic_care_state_mapping.json`; `cart_trace/reconstruction.py` |
| Equal-priority conflict | Irreconcilable disagreement among equally authoritative canonical mappings | conflicting mapped states at the same interval | Conflict duration remains represented on the canonical time axis | Resolves to explicit `unknown` with uncertainty and contributing source IDs | `cart_trace/reconstruction.py`; conflict synthetic fixture |
| Acute-care return | Post-discharge transition into qualifying acute care | prior discharge plus subsequent emergency/inpatient qualifying event | Evaluated relative to discharge and metric-specific follow-up horizon | `acute_care_return` is a transition type, never a care state; negative results require sufficient follow-up | `cart_trace/metrics.py`; metric contract |

**Interpretation:** CART-TRACE separates source evidence, deterministic transformation, canonical representation, validation, and metric derivation so that every major result can remain traceable from source record to scholarly output.
